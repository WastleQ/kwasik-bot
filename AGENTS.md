## 📌 Проект
**Kwasik Bot** — интерактивный Twitch RPG-бот по мотивам аниме/манхвы *Solo Leveling*. 
Бот обрабатывает чат-команды в реальном времени, ведёт систему прокачки, инвентаря, сражений в подземельях и поднятия рангов (от E до S) для зрителей трансляции.

## 🛠 Технический стек & Архитектура
* **Язык:** Python 3.11+ (строго асинхронный код `asyncio`).
* **Twitch API & WebSockets:** `twitchio` (v2.x+).
* **База данных:** SQLite / PostgreSQL через асинхронный ORM (`SQLAlchemy` async / `peewee-async`).
* **Кэширование & Очереди:** Redis (для лимитов команд, кулдаунов и сессий).
* **Форматирование & Линтинг:** `ruff` (не использовать flake8/black).

## 📐 Правила написания кода (Code Style & Guidelines)
1. **Асинхронность:** Все функции ввода-вывода (БД, сетевые запросы, отправка сообщений в чат) должны быть `async def`. Запрещены блокирующие вызовы (`time.sleep()`, `requests.get()`).
2. **Типизация:** Все аргументы функций и возвращаемые значения должны иметь Type Hints (`from typing import Optional, List...`).
3. **Обработка ошибок:**
   * Не «глотать» исключения `except Exception: pass`.
   * Ошибки чат-команд должны логироваться и возвращать понятный понятный ответ пользователю в Twitch (например: `⚠️ У вас недостаточно золота!`).
4. **Безопасность:**
   * **Никогда** не хардкодить OAuth-токеры, Client ID и ключи в коде. Используй `pydantic-settings` или `python-dotenv` из `.env`.
5. **Чистота файлов:** Не переписывать весь файл целиком, если требуется изменить одну функцию. Делать изменения точечно.
