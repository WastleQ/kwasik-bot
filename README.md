# ⚔️ Kwasik — Solo Leveling Twitch RPG Bot

Игровой Twitch-бот в стиле аниме/манхвы **«Поднятие уровня в одиночку» (Solo Leveling)**.  
Превращает чат стрима в интерактивную RPG: зрители прокачивают ранги (от E до S), сражаются с монстрами в подземельях и вратах, добывают экипировку и магические кристаллы, крафтят легендарное снаряжение, создают группы (пати), выполняют ежедневные квесты Системы, сражаются в пошаговых PvP-дуэлях и участвуют в рейдах на мировых боссов.

---

## 🌟 Основные игровые особенности
* **🛡 Система рангов и прогрессии:** Прокачка уровня, распределение очков характеристик (`сила`, `ловкость`, `живучесть`, `интеллект`, `восприятие`) и смена рангов от E до S.
* **👑 Титулы и Достижения:** Разблокировка уникальных титулов с бонусами к характеристикам за выполнение достижений.
* **🗡 Подземелья и Врата:** Одиночные зачистки врат с боссами, выпадением лута и магических кристаллов (E–S ранги).
* **✨ Магическая система:** Боевые заклинания (`Огненный шар`, `Удар молнии`, `Метеорит`) с расходом маны, а также заклинания лечения (`Исцеление`) и защиты (`Магический щит`).
* **⚒️ Крафт предметов:** Создание уникального элитного снаряжения из редких кристаллов и базового оружия.
* **👥 Система групп (Пати):** Объединение до 5 охотников для совместных рейдов по вратам и сражений с сильными монстрами.
* **📅 Ежедневные квесты Системы:** Ежедневные задания на охоту с ценными наградами (AP, опыт, золото).
* **⚔️ Пошаговые PvP-дуэли:** Тактические дуэли между зрителями в чате с инициативой, уклонениями и критическими ударами.
* **🎒 Инвентарь, Торговля и Рынок:** Пакетная продажа, экипировка предметов и передача золота/предметов другим зрителям (`!передать`).
* **🏆 Таблицы лидеров:** Топы по уровню (`!топ`), золоту (`!топ_золото`) и победам в PvP (`!топ_пвп`).

## 📜 Полный список команд

### 👤 1. Профиль и Информация (`InfoCog`)
| Команда | Описание |
| :--- | :--- |
| `!профиль` / `!статы` | Карточка охотника: ранг, уровень, HP, MP, золото, активный титул, экипировка и характеристики. |
| `!топ` | Топ-5 охотников чата по уровню и опыту. |
| `!топ_золото` | Топ-5 богачей чата по количеству золота. |
| `!топ_пвп` | Таблица лидеров по победам в PvP-дуэлях. |
| `!достижения` | Список разблокированных достижений охотника. |
| `!титулы` | Список всех доступных титулов и условий их получения. |
| `!титул <название>` | Сменить активный титул персонажа (гибкий поиск без учета регистра). |
| `!заклинания` | Список доступных магических заклинаний, их стоимость (MP) и эффекты. |
| `!помощь` / `!команды` | Справка по всем доступным командам бота. |
| `!гит` / `!git` | Ссылка на официальный GitHub-репозиторий проекта. |
| `!правила` / `!rules` | Ссылка на подробный справочник и правила (Wiki). |

### ⚔️ 2. Игровой процесс и Охота (`GameplayCog`)
| Команда | Описание |
| :--- | :--- |
| `!охота` | Вылазка в подземелье текущих врат. Дает опыт, золото, шанс выбить лут/кристаллы и отображает остаток HP/MP и нанесенный урон. |
| `!охота каст <заклинание>` | Атака монстра в подземелье выбранным заклинанием (`шар`, `молния`, `метеор`). |
| `!отдых` | Полное восстановление HP и маны (MP) персонажа. |
| `!квест` | Получить ежедневный квест Системы на охоту в вратах соответствующего ранга. |
| `!награда` | Забрать награду за выполненный ежедневный квест (+3 AP, EXP, золото, полное восстановление). |
| `!врата` | Список доступных для перехода врат (от E до S ранга). |
| `!переход <ID>` | Сменить текущую локацию (врата) для охоты. |
| `!прокачка <стат> [кол-во]` / `!кач` | Распределить очки характеристик (`сила`, `ловкость`, `живучесть`, `интеллект`, `восприятие`). |

### 🎒 3. Инвентарь и Магазин (`ItemsCog`)
| Команда | Описание |
| :--- | :--- |
| `!инвентарь` | Показывает рюкзак охотника (с защитой от превышения лимита Twitch). |
| `!надеть <предмет>` | Экипирует оружие, броню или аксессуар из рюкзака. |
| `!снять <слот>` | Снимает экипировку из слота (`оружие`, `броня`, `аксессуар`). |
| `!пить <зелье>` / `!использовать` | Восстанавливает HP или MP из зелья в рюкзаке. |
| `!магазин` | Ассортимент товаров по категориям (Расходники, Экипировка, Кристаллы). |
| `!купить <предмет>` | Покупка предмета за золото. |
| `!продать <предмет> [кол-во]` | Пакетная продажа предметов в магазин за полцены (с авто-снятием экипировки). |
| `!крафты` | Список доступных рецептов крафта элитного снаряжения. |
| `!крафт <название>` | Создать легендарный предмет из кристаллов и базы. |
| `!передать золото @юзер <сумма>` | Перевести золото другому зрителю в чате. |
| `!передать предмет @юзер <название>` | Передать предмет из своего рюкзака другому зрителю. |

### 👥 4. Группы и Пати (`PartyCog`)
| Команда | Описание |
| :--- | :--- |
| `!пати` | Статус текущей группы (пати). |
| `!пати создать` | Создать новую группу (ты становишься лидером). |
| `!пати инвайт @юзер` | Пригласить игрока в пати (только лидер). |
| `!пати принять` | Принять приглашение в группу. |
| `!пати покинуть` | Покинуть группу (или распустить, если лидер). |
| `!пати ход <ID>` | Сменить локацию группы во врата (только лидер). |
| `!пати охота` | Совместный рейд всей группы на монстров врата. |

### ⚔️ 5. PvP Дуэли (`PvPCog`)
| Команда | Описание |
| :--- | :--- |
| `!дуэль @юзер` | Бросить вызов другому зрителю на поединок. |
| `!принять` | Принять вызов на дуэль (запуск пошаговой тактической битвы). |
| `!отклонить` | Отклонить вызов на дуэль. |
| `!бой удар` | Физическая атака в пошаговой дуэли. |
| `!бой каст <заклинание>` | Магическая атака, лечение или создание магического щита в дуэли. |

### 🐲 6. Рейды на Боссов (`RaidCog`)
| Команда | Описание |
| :--- | :--- |
| `!рейд` | Проверить статус активного мирового босса / запустить рейд. |
| `!атака` | Нанести урон мировому боссу вместе со всеми зрителями. |

## 🏗 Архитектура и Структура проекта
* **`main.py`** — Точка входа, инициализация бота TwitchIO, фоновые задачи и логирование.
* **`src/config.py`** — Конфигурация и переменные окружения.
* **`src/cogs/`** — Модульные команды бота (Info, Gameplay, Items, Party, PvP, Raid).
* **`src/engine.py`** — Игровая математика и формулы (урон, магия, криты, уровни, ранги, смерть).
* **`src/models.py`** — Диспетчер базы данных (`DBManager`) с поддержкой пула PostgreSQL (`asyncpg`) и SQLite.
* **`src/data.py`** — Статические справочники (врата, монстры, предметы, экипировка, заклинания, рецепты).
