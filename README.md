# ⚔️ Kwasik — Solo Leveling Twitch RPG Bot

Игровой Twitch-бот в стиле аниме/манхвы **«Поднятие уровня в одиночку» (Solo Leveling)**.  
Превращает чат стрима в интерактивную RPG: зрители прокачивают ранги, сражаются с монстрами в подземельях, выбивают снаряжение, создают группы (пати) и устраивают PvP-дуэли.

---

## 🌟 Основные особенности

* **🛡 Система рангов и прогрессии:** От E-ранга до S-ранга и Национального уровня.
* **🗡 Подземелья (Dungeons):** Одиночные зачистки врат с боссами и выпадением лута (мечи, броня, зелья).
* **👥 Система групп (Пати):** Объединение до 5 охотников для совместных рейдов по вратам и сражений с сильными монстрами.
* **⚔️ PvP & Рейды:** Дуэли между зрителями в чате и совместные рейды на мировых боссов.
* **🎒 Инвентарь и Рынок:** Продажа и экипировка предметов с динамическим расчетом характеристик.
* **🏆 Таблица лидеров:** Команда `!топ` для определения сильнейших охотников чата.

## 📜 Полный список команд

### 👤 1. Профиль и Информация (`InfoCog`)
| Команда | Описание |
| :--- | :--- |
| `!профиль` | Показывает карточку охотника: ранг, уровень, HP, ману, золото и характеристики. |
| `!топ` | Выводит топ-5 сильнейших охотников чата по уровню и опыту. |
| `!помощь` | Выводит краткую справку по основным командам бота. |

### ⚔️ 2. Игровой процесс и Охота (`GameplayCog`)
| Команда | Описание |
| :--- | :--- |
| `!охота` | Вылазка в подземелье. Дает опыт, золото и шанс выбить лут. Есть перезарядка (cooldown). |
| `!отдых` | Восстанавливает HP и ману персонажа. |
| `!прокачка <стат>` | Распределяет свободные очки характеристик (`сила`, `ловкость`, `интеллект`, `выносливость`). |

### 🎒 3. Инвентарь и Магазин (`ItemsCog`)
| Команда | Описание |
| :--- | :--- |
| `!инвентарь` | Показывает список предметов в твоем рюкзаке. |
| `!надеть <предмет>` | Экипирует оружие, броню или аксессуар из инвентаря, повышая характеристики. |
| `!магазин` | Показывает ассортимент товаров, доступных для покупки за золото. |
| `!купить <предмет>` | Покупает предмет в магазине (например, `!купить Зелье HP`). |
| `!продать <предмет>` | Продает предмет из инвентаря в магазин за золото. |

### 👥 4. Группы и Пати (`PartyCog`)
| Команда | Описание |
| :--- | :--- |
| `!пати` | Показывает текущий статус группы (пати), в которой ты состоишь. |
| `!пати создать` | Создает новую группу (ты становишься лидером). |
| `!пати инвайт @юзер` | Приглашает другого зрителя в группу (только для лидера). |
| `!пати принять` | Принимает приглашение в группу от лидера. |
| `!пати покинуть` | Покидает текущую группу (или распускает ее, если ты лидер). |
| `!пати ход <ID_врат>` | Изменяет локацию группы во врата (только для лидера). |
| `!пати охота` | Начинает совместную охоту всей группой в выбранных вратах. |

### ⚔️ 5. PvP Дуэли (`PvPCog`)
| Команда | Описание |
| :--- | :--- |
| `!дуэль @юзер` | Вызывает другого зрителя в чате на PvP-поединок. |
| `!принять` | Принимает вызов на дуэль от другого игрока. |
| `!отклонить` | Отклоняет полученный вызов на дуэль. |

### 🐲 6. Рейды на Боссов (`RaidCog`)
| Команда | Описание |
| :--- | :--- |
| `!рейд` | Проверяет статус текущего мирового босса / запускает совместный рейд. |
| `!атака` | Наносит урон активному боссу рейда вместе с другими зрителями. |

## 🏗 Архитектура и Структура проекта

* **`main.py`** — Точка входа, инициализация бота TwitchIO и подключение когов.
* **`src/cogs/`** — Модульные команды бота (информация, геймплей, инвентарь, пати, PvP, рейды).
* **`src/engine.py`** — Игровая логика (расчет урона, повышение уровней, рангов, смерти).
* **`src/models.py`** — Описание моделей данных и работы с базой данных (SQLite/SQLAlchemy).
* **`src/data.py`** — Статические справочники (врата, монстры, предметы, экипировка).

## 🚀 Быстрый старт и Установка

### 1. Клонирование репозитория
```bash
git clone https://github.com/WastleQ/kwasik-bot.git
cd kwasik-bot
```

### 2. Настройка виртуального окружения и зависимостей
```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Настройка конфигурации (`.env`)
Создайте файл `.env` в корне проекта и укажите необходимые токены:
```env
TWITCH_TOKEN=oauth:ваш_токен_твич
CHANNEL=имя_канала_для_подключения
```

### 4. Запуск тестов и линтера
```bash
PYTHONPATH=. pytest
ruff check .
```

### 5. Запуск бота
```bash
python main.py
```
